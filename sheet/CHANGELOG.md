# [1.0.1] - Bug fixes and improvements

* Fix `Sheet` content updates while the sheet is still initializing
* Prevent scrolling beyond the maximum position and fix related overscroll/bounce calculations
* Allow resizing a sheet larger than `minResizableExtent` when `resizable` is true
* Add `draggable` property to `CupertinoSheetRoute`
* Fix `PopScope` handling in `SheetRoute`
